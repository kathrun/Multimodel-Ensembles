# GRAPHING SCRIPTS

Each file creates figures for the final paper.

- CompareMeanMed.py: Creates Figure 2 -- comparison between deterministic, median, and mean forecasts for all thresholds and metrics.
- Simple2x2.py: Figure 4 -- Creates a 2x2 graph comparing Simple NPC performance for all four metrics (PoD, PoFD, HSS, Bias) for a single threshold.
- Simple4x4.py: Figure 5 -- Creates all graphs comparing NPC performance for all metrics and all thresholds. Each indvidual graph is for a single metric and single threshold. 
- Best4x4.py: figure 6 -- Is the same as the simple 4x4 but for the Best of NPC configuration. 
- modtreshcomp.py is the comparsion for scaled thresholds for HSS and Bias
- npc_comparison.py Single station, single event, single threshold (similar to Moreley paper)
